02 / QUICK REFERENCE

Git, from init to push.

Run these in the root folder of your project using a terminal.

POWERSHELL / TERMINAL
git init
git add .
git commit -m "Initial project commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
If your remote is already set, don't add it again. For subsequent updates use git add ., git commit -m "Update project", and git push.
